# Client logos for the dashboard

One file per client, named for the slug: `steve-pallas-jewellery.png`.

- PNG with a transparent background, white or light artwork (the canvas is near black).
- At least 2x the display size: 60px tall minimum, 400px wide maximum.
- The file appears automatically in the dashboard header beside the Ready to Rank logo.
- No file means the client's name shows in their accent colour instead, so nothing breaks.

The accent colour is `pa_launch_briefs.accent` and must be **sampled from the client's logo
file**, not taken from their website CSS.
